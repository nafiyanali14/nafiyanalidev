## 🚀 What I'm Building

### 🧩 NEXUS — Civic Technology Platform

> **See a problem. Connect people. Turn it into a solution.**

NEXUS is a civic-tech platform focused on helping communities identify real problems, connect people around them, and work toward solutions.

📍 Focus: **Jammu & Kashmir, India**

The project explores:

* 🗺️ Real geographic problem mapping
* 📍 Location-based civic issues
* 👥 Community connections
* 💬 Discussions and support
* 📊 Impact tracking
* 🔐 User authentication
* ⚡ Real-time data
* ☁️ Supabase backend

---

### 🌐 UNIXN — Social Platform

UNIXN is a social platform concept focused on meaningful connections and modern social interaction.

The project explores:

* 👤 User profiles
* 🤝 Friend circles
* 📝 Posts and moments
* 💬 Real-time messaging
* 🔔 Notifications
* ❤️ Likes, saves and interactions
* 🔐 Authentication & user identity
* ⚡ Real-time backend systems

Built with a focus on **professional UI, scalability and real functionality** rather than simple prototypes.
